# Indonesian Digital Startup Funding & Investment Trends Dataset 🚀🇮🇩

An automated synthetic dataset and interactive business analytics web dashboard tracking digital startup investments, funding stages, capital amounts in USD, and sector distribution across Indonesia.

## 📊 Dataset Features
*   **Scope:** Digital startups across major innovation hubs in Indonesia (Jakarta, Bandung, Surabaya, Yogyakarta, Bali).
*   **Attributes:** Startup Name, Sector/Industry (Fintech, Edtech, E-Commerce, SaaS, Healthtech, Agritech, Logistics), Funding Stage (Pre-Seed, Seed, Series A, Series B, Series C+), Funding Amount (USD), Founded Year, Location City, and Lead Investor Type.

## 🚀 App Features
*   **Executive Metrics:** Real-time summary of Total Funding Capital (USD), Total Active Startups Tracked, Average Funding per Deal, and Top Funded Sector.
*   **Interactive Visualizations:** Comparative bar charts for funding distribution by sector and funding stage using Plotly.
*   **Dynamic Filters:** Filter data effortlessly by funding stage, sector, and city.
*   **Raw Data Explorer:** Search, filter, and download raw tabular data directly from the browser.
