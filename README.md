# Indonesian E-Commerce Logistics & Customer Satisfaction Dataset

An automated synthetic dataset and interactive analytics web dashboard tracking e-commerce logistics performance, delivery times, shipping costs, and customer satisfaction ratings across Indonesia.

## Dataset Features
*   **Scope:** E-commerce delivery transactions across major island regions and provinces in Indonesia.
*   **Attributes:** Order ID, Shipping Provider (JNE, J&T, SiCepat, GoSend, GrabExpress), Delivery Type (Same-Day, Express, Regular, Cargo), Destination Province, Shipping Cost (IDR), Estimated Delivery Days, Actual Delivery Days, Delivery Status (On-Time, Delayed), and Customer Satisfaction Rating.

## App Features
*   **Executive Metrics:** Real-time summary of total shipments tracked, on-time delivery rate, average shipping cost, and average customer rating.
*   **Interactive Visualizations:** Comparative analysis for delivery performance by logistics provider and shipping status breakdown using Plotly.
*   **Dynamic Filters:** Filter data effortlessly by delivery type, shipping provider, and delivery status.
*   **Raw Data Explorer:** Search, filter, and download raw tabular data directly from the browser.
